▦ PIXEL ART ATLAS

1.4 million pixel sprites,
one simple API.

Search 1,409,404 free 16×16 sprites across 6,194 subjects, plus 244 animated VFX (pixelfx) as ready-to-play sprite sheets. Use them in your games via direct links or atlas sheets. No key, no signup.

API reference

GET /api/search?q=golden+sword&subject=&limit=60&offset=0

Full-text search over captions and subject names. Returns sprite metadata: id, caption, subject, atlas sheet and cell coordinates.

GET /api/sprite?id=123&scale=4

One sprite as a PNG, nearest-neighbour upscaled (scale 1–16, default 4). Long-lived CDN cache — hot-link it straight into your game.

GET /api/info?id=123

Metadata for a single sprite as JSON.

GET /api/subjects

All 6,194 subjects with sprite counts.

GET /api/random?n=24

Random sprites — handy for placeholders and demos.

GET /atlases/sheet-000.webp

Raw atlas sheets: 2048×2048 WebP, a 128×128 grid of 16×16 sprites. Sprite id → sheet = ⌊id / 16384⌋, x = (id mod 128) × 16, y = ⌊(id mod 16384) / 128⌋ × 16.

VFX — animated effects (pixelfx)

GET /api/vfx?q=explosion&category=fire&limit=60&offset=0

Search 244 animated VFX (232 effects + 12 acted moves). Returns name, description, tags, fps, frame count/size, pivot and sheet links.

GET /api/vfx?id=fire/campfire

One effect's descriptor. The full sheet JSON at /vfx/fire/campfire.json adds per-frame rects in the common atlas format {frames: [{x, y, w, h}], fps …} — it drops straight into FlowVFX-style loaders.

GET /vfx/fire/campfire.webp

The effect's sprite sheet (lossless WebP, transparent). Play it by stepping frames at its fps; loop effects loop seamlessly.

Use it in a game (canvas)

// find sprites
const r = await fetch('/api/search?q=potion&limit=24').then(r => r.json());
const s = r.results[0];

// draw one from its atlas sheet
const img = new Image();
img.src = s.atlas;                       // /atlases/sheet-003.webp
await img.decode();
ctx.imageSmoothingEnabled = false;
ctx.drawImage(img, s.x, s.y, 16, 16, 0, 0, 64, 64);

// or simply hot-link the PNG
// <img src="/api/sprite?id=123&scale=4">
