▦ PIXEL ART ATLAS

1.4 million pixel sprites,
one simple API.

Search 1,409,404 free 16×16 sprites across 6,194 subjects, plus 244 animated VFX (pixelfx), 841 sound effects (Kenney + jsfxr), 4,101 3D models (KayKit, Kenney, Quaternius) and 83 Kenney packs — all free for your games via direct links. No key, no signup.

API reference

GET /api/search?q=golden+sword&subject=&limit=60&offset=0

Full-text search over captions and subject names. Returns sprite metadata: id, caption, subject, atlas sheet and cell coordinates.

GET /api/sprite?id=123&scale=4

One sprite as a PNG, nearest-neighbour upscaled (scale 1–16, default 4). Long-lived CDN cache — hot-link it straight into your game.

GET /api/info?id=123

Metadata for a single sprite as JSON.

GET /api/subjects

All 6,194 subjects with sprite counts.

GET /api/random?n=24

Random sprites — handy for placeholders and demos.

GET /atlases/sheet-000.webp

Raw atlas sheets: 2048×2048 WebP, a 128×128 grid of 16×16 sprites. Sprite id → sheet = ⌊id / 16384⌋, x = (id mod 128) × 16, y = ⌊(id mod 16384) / 128⌋ × 16.

VFX — animated effects (pixelfx)

GET /api/vfx?q=explosion&category=fire&limit=60&offset=0

Search 244 animated VFX (232 effects + 12 acted moves). Returns name, description, tags, fps, frame count/size, pivot and sheet links.

GET /api/vfx?id=fire/campfire

One effect's descriptor. The full sheet JSON at /vfx/fire/campfire.json adds per-frame rects in the common atlas format {frames: [{x, y, w, h}], fps …} — it drops straight into FlowVFX-style loaders.

GET /vfx/fire/campfire.webp

The effect's sprite sheet (lossless WebP, transparent). Play it by stepping frames at its fps; loop effects loop seamlessly.

SFX — sound effects (Kenney CC0 + jsfxr)

GET /api/sfx?q=coin&group=&limit=60&offset=0

Search 841 sounds: Kenney's CC0 audio packs (interface, impacts, RPG, sci-fi, jingles, voiceover…) plus 88 jsfxr-generated retro presets, each with its reproducible sfxr.me code.

GET /api/sfx?id=kenney/interface-sounds/click_001

One sound's metadata; the file itself is at its url (OGG) — hot-link it into your game.

3D Models — GLB (KayKit · Kenney · Quaternius, CC0)

GET /api/models?q=knight&source=kaykit&pack=&animated=1&limit=60&offset=0

Search 4,101 GLB models: rigged animated characters, dungeon/city/nature kits and props. Returns download URL, size, animation count and a thumbnail.

GET /api/models?id=kaykit/character-pack-adventures/Knight

One model's metadata. Kenney kit models share a palette texture — keep the pack's Textures/ folder next to the GLBs (it sits beside them in /models/kenney/<pack>/Textures/).

Kenney 2D — sprite & UI packs (CC0)

GET /api/packs?q=ui&limit=60&offset=0

Browse 40 Kenney 2D packs (UI, roguelike, tiny series, platformer…). Small packs ship individual PNG tiles; large packs ship a generated contact sheet.

GET /api/packs?id=kenney/ui-pack

One pack's contents: sheet URLs, tile URLs, and for contact-sheet packs the per-tile frame rects — the same atlas pattern as the sprite API.

Use it in a game (canvas)

// find sprites
const r = await fetch('/api/search?q=potion&limit=24').then(r => r.json());
const s = r.results[0];

// draw one from its atlas sheet
const img = new Image();
img.src = s.atlas;                       // /atlases/sheet-003.webp
await img.decode();
ctx.imageSmoothingEnabled = false;
ctx.drawImage(img, s.x, s.y, 16, 16, 0, 0, 64, 64);

// or simply hot-link the PNG
// <img src="/api/sprite?id=123&scale=4">
